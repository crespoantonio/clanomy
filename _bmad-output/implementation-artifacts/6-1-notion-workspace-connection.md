## Story

As a Premium User,
I want to connect my Notion account and select a target database,
so that I can link my family bot records to my existing financial workspace in Notion.

## Acceptance Criteria

1. **Family Database Schema & Encrypted Credential Persistence**:
   - Extend the `Family` SQLModel in `src/db/models.py` with the following Notion configuration fields:
     - `notion_api_key: Optional[str] = Field(default=None)` (stores base64 ciphertext generated by `EncryptionService.encrypt()`)
     - `notion_database_id: Optional[str] = Field(default=None, index=True)`
     - `notion_database_name: Optional[str] = Field(default=None)`
     - `notion_connected_at: Optional[datetime] = Field(default=None)`
   - Sensitive Notion API integration tokens must NEVER be stored in plaintext. Always encrypt via `EncryptionService.encrypt()` before persisting to Postgres/SQLite.
   - When retrieving connection details, `notion_api_key` must be decrypted in memory using `EncryptionService.decrypt()` only when instantiating the Notion client.

2. **Notion Client Wrapper & Workspace Discovery (`NotionService`)**:
   - Implement `NotionService` in `src/services/notion_service.py` wrapping `notion-client`:
     - `validate_token(api_key: str) -> bool`: Verifies that the provided token is valid by querying the Notion Users/Search API.
     - `search_databases(api_key: str) -> List[Dict[str, Any]]`: Searches for all database objects accessible by the integration using `client.search(filter={"property": "object", "value": "database"})`.
     - Extracts and returns a clean list of databases with metadata: `id`, `title` (plain text string or fallback `"Untitled Database"`), `url`, `properties` (dictionary of property names and types).
     - `get_database_details(api_key: str, database_id: str) -> Dict[str, Any]`: Retrieves specific database metadata via `client.databases.retrieve(database_id=database_id)`.
     - Handles Notion API errors (`APIResponseError`, invalid tokens, rate limits, network timeouts) gracefully, raising typed exceptions (`NotionAuthError`, `NotionDatabaseNotFoundError`, `NotionServiceError`) with user-friendly error messages.

3. **Workspace & Database Connection Management**:
   - In `NotionService`:
     - `connect_database(family_id: UUID, api_key: str, database_id: str, database_name: Optional[str] = None) -> Dict[str, Any]`:
       - Validates token and target database access against Notion API.
       - Encrypts `api_key` using `EncryptionService.encrypt()`.
       - Atomically updates the `Family` record with `notion_api_key`, `notion_database_id`, `notion_database_name`, and `notion_connected_at=datetime.now(timezone.utc)`.
       - Returns the connection summary dictionary.
     - `disconnect_workspace(family_id: UUID) -> bool`:
       - Clears `notion_api_key`, `notion_database_id`, `notion_database_name`, and `notion_connected_at` on the `Family` record.
       - Returns `True` upon successful disconnection.
     - `get_family_notion_status(family_id: UUID) -> Dict[str, Any]`:
       - Returns a status dictionary: `is_connected: bool`, `database_id: Optional[str]`, `database_name: Optional[str]`, `connected_at: Optional[datetime]`, `has_valid_token: bool`.

## Dev Notes

### Architecture & Service Design

- **Notion SDK Integration**:
  The official `notion-client` Python package provides native async support via `notion_client.AsyncClient`:
  ```python
  from notion_client import AsyncClient, APIResponseError
  
  async def search_databases(api_key: str) -> List[Dict[str, Any]]:
      async with AsyncClient(auth=api_key) as notion:
          try:
              response = await notion.search(filter={"property": "object", "value": "database"})
              databases = []
              for db in response.get("results", []):
                  title_list = db.get("title", [])
                  title_text = "".join([t.get("plain_text", "") for t in title_list]) or "Untitled Database"
                  databases.append({
                      "id": db.get("id"),
                      "title": title_text,
                      "url": db.get("url"),
                      "properties": list(db.get("properties", {}).keys())
                  })
              return databases
          except APIResponseError as e:
              if e.code == "unauthorized":
                  raise NotionAuthError("Invalid Notion API key or token.")
              raise NotionServiceError(f"Notion API error: {e.message}")
  ```

- **Credential Encryption & Storage Pattern**:
  - `notion_api_key` in `Family` stores the Fernet ciphertext:
    ```python
    encryption = EncryptionService()
    encrypted_token = encryption.encrypt(raw_api_key)
    family.notion_api_key = encrypted_token
    family.notion_database_id = database_id
    family.notion_database_name = database_name
    family.notion_connected_at = datetime.now(timezone.utc)
    ```
  - When accessing Notion for queries or mirroring:
    ```python
    if not family.notion_api_key:
        raise NotionServiceError("Notion is not connected for this family.")
    decrypted_token = encryption.decrypt(family.notion_api_key)
    ```

### Anti-Patterns to Prevent

- **Plaintext Secrets**: Never store raw Notion API tokens in database columns or logs. Always encrypt with `EncryptionService.encrypt()` and mask tokens in logs (`secret_***`).
- **Synchronous Network Calls**: Never use synchronous HTTP calls for Notion SDK requests on the event loop. Always use `AsyncClient` or wrap calls in `asyncio.to_thread()`.
- **Tenant Cross-Contamination**: Always enforce `family_id` scoping when updating or querying Notion configuration.
- **Assumed Database Schema**: Notion databases may have custom property names. In Story 6.1, store the database ID and property names, and handle missing properties gracefully when preparing for Story 6.2 mirroring.
- **Unclear User Feedback**: Provide clear error messages when a token is invalid or when a database has not been shared with the integration.
