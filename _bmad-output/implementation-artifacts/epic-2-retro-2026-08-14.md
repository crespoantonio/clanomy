## 2. Retrospective Discussion Summary

### What Went Well
* **3-Second Rule SLA Compliance:** The API decouples ingress acknowledgement from AI processing. Ingress returns `200 OK` in <100ms, pushing Whisper, Ollama, and DB writes to background async tasks.
* **Dual Inbound Routing (Text & Voice):** Unified messaging ingress at `/api/v1/messages` seamlessly supports both plain text messages and binary audio/voice notes.
* **Self-Healing Audio Resolver:** Enhanced `WhisperService` to automatically resolve Telegram `getFile` JSON endpoints into direct audio stream downloads without requiring manual file extraction logic.
* **Comprehensive Zero-to-Telegram Guide:** Rewrote [Manual Testing Guide.md](file:///c:/Users/cresp/Documents/Projectos/FamFin-AI/Manual%20Testing%20Guide.md) specifically for Windows + Podman + ngrok with copy-pasteable n8n workflows.

### Challenges and Lessons Learned
* **CPU Inference Latency:** On CPU-only environments without GPU passthrough, Llama3 8B model inference can take 12–18 seconds. The initial 10s timeout caused `asyncio.TimeoutError` and was adjusted to 60s.
* **n8n Expression Parsing:** Direct interpolation of objects in n8n HTTP body resulted in `[object Object]`. Resolved using `{{ JSON.stringify($json) }}`.
* **Telegram Webhook HTTPS Requirement:** Telegram requires valid public HTTPS URLs. Documented the ngrok setup and `WEBHOOK_URL` environment variable for local Podman containers.
